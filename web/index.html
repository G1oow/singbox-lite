Measurement API

Node metadata
GET /api/v1/nodes — returns the node list with location, provider and advertised capacity.

Latency probe
GET /api/v1/latency?node=… — issues five sequential probes and reports round-trip time with jitter and packet loss.

Access is rate limited to 60 requests per minute per address. Bulk access requires an API key issued to registered operators.

About Netmeter

Netmeter measures the throughput and responsiveness of your connection against a network of test nodes hosted at internet exchange points.

Each test sends eight latency probes, ramps up a small number of parallel streams, then reports the mean of the settled second half of the run so slow start does not distort the figure.

No account is required. Tests run in the browser and results stay on this device unless you choose to export them.
