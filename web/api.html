Measurement API

Node metadata, latency probes and throughput sessions. All endpoints return JSON and are safe to call from a browser.

Authentication

Public reads need no credentials. Bulk access and result exports require an operator key, sent as a bearer token.

# public read
curl -s https://netmeter.example/api/v1/nodes

# operator call
curl -s -H "Authorization: Bearer $NETMETER_KEY" \
  https://netmeter.example/api/v1/sessions?limit=50
Keys are scoped per account. A key issued for exports cannot start measurement sessions.

Node metadata

GET /api/v1/nodes

Returns every node with its exchange, operator and advertised capacity. Capacities are the ceiling the node is provisioned for, not a guarantee of your measured rate.

{
  "nodes": [
    {
      "id": "hkg",
      "city": "Hong Kong",
      "exchange": "HKIX",
      "operator": "Netmeter APAC",
      "capacity_mbps": 940,
      "status": "online"
    }
  ]
}

Latency probe

GET /api/v1/latency?node=hkg&probes=8

Runs sequential probes against one node and reports mean round-trip time, jitter and packet loss. The browser test uses the same routine with eight probes.

ParameterNotes
nodeNode id from /nodes. Required.
probes1–16, default 5. Higher counts cost proportionally more of your rate budget.
 
{
  "node": "hkg",
  "probes": 8,
  "rtt_ms": 11.2,
  "jitter_ms": 0.8,
  "loss_pct": 0
}

Throughput session

POST /api/v1/sessions

Opens a measurement session and returns the stream URLs to run against. Sessions expire after 120 seconds if no streams are started.

{
  "session_id": "s_7f3ac1",
  "node": "hkg",
  "expires_in": 120,
  "streams": {
    "download": "/api/v1/sessions/s_7f3ac1/down",
    "upload": "/api/v1/sessions/s_7f3ac1/up"
  }
}
Upload is capped at 100 Mbps per session. The cap protects shared capacity on the node; it is not a limit of your link.

Result object

Once a session closes, GET /api/v1/sessions/{id} returns the settled figures. Values are the mean of the second half of each transfer, which keeps slow start out of the average.

{
  "session_id": "s_7f3ac1",
  "finished_at": "2025-03-11T09:41:22Z",
  "ping_ms": 11.2,
  "jitter_ms": 0.8,
  "download_mbps": 872.46,
  "upload_mbps": 91.48,
  "bytes_download": 1374389534,
  "bytes_upload": 143327232
}

Rate limits

ScopeLimitWindow
Public reads60per minute, per address
Latency probes20per minute, per address
Sessions6per minute, per address
Operator exports600per hour, per key
Every response carries X-RateLimit-Remaining. A 429 includes Retry-After in seconds.

Errors

Errors use a stable shape so clients can branch on code rather than parsing prose.

{
  "error": {
    "code": "node_offline",
    "message": "Requested node is not accepting sessions.",
    "request_id": "req_91b2"
  }
}
StatusCode
400invalid_parameter
401missing_key
404unknown_node
409node_offline
429rate_limited
