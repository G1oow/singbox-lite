Why the figures differ from your provider's

A plan advertises a provisioning ceiling, not a moment-to-moment rate. What you measure depends on the path to a specific node, how congested the exchange is at that hour, and what else is using the link.

We report what the transfer did, not what it should have done. If a run lands at 72% of your plan, that is the honest number for that minute against that node.

Methodology

Every run follows the same four steps. Nothing is cached between runs, so a retest is a genuinely new measurement.

Latency probes

Eight sequential probes to the selected node. The mean becomes the ping figure; jitter is the squared deviation across those eight.

Download ramp

A small number of parallel streams start at once and run for twelve seconds. The first three seconds are slow start and are excluded from the average.

Upload ramp

The same stream count in reverse for nine seconds. Upload sessions are capped at 100 Mbps per session to keep shared node capacity available.

Settled average

The reported figure is the mean of the second half of each transfer. Peaks are never reported, because a peak is not a rate you can sustain.

Where the nodes are

Nodes sit inside public internet exchange points rather than single-homed data centres, which keeps the path between you and the measurement point short and predictable.

  • HKIX — Hong Kong
  • SGIX — Singapore
  • JPIX — Tokyo
  • Any2 West — Los Angeles
  • DE-CIX — Frankfurt
  • Equinix SY1 — Sydney

Capacity per node is listed on the status page, along with any incident that touched a measurement window.
